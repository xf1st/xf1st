Флагманский Проект

TravelLM (.ru / .world)

Комплексная AI-платформа для генерации туристических маршрутов

Некоммерческий продукт в эксплуатации

Генерация персонализированных маршрутов с помощью нейросетей

Задача: собрать в одном сервисе создание персонального маршрута, подбор впечатлений и помощь AI-гида.

Моя роль: развиваю личный проект с AI-инструментами: интерфейс, серверная логика, база данных, промпты и деплой.

Решение: Next.js-приложение с PostgreSQL, потоковыми ответами LLM, медиалентой и админ-панелью для управления промптами и контентом.

Результат: один продукт объединяет 4 пользовательских модуля и работает в двух доменных версиях.

Sipliy Folder VPS

Менеджер загрузок на VPS: веб-интерфейс, API, браузерное расширение и Telegram-бот

Node.js / Express + Extension + Telegram

Быстрые загрузки файлов на VPS и браузерное расширение в один клик

Задача: переносить загрузки с рабочего устройства на VPS без ручного входа на сервер.

Моя роль: разрабатываю с AI-инструментами backend и API, веб-интерфейс, браузерное расширение, Telegram-бота; настраиваю деплой на VPS.

Решение: Express API управляет aria2c по JSON-RPC, расширение и Telegram-бот передают ссылки на сервер, VirusTotal проверяет файлы. Для запуска — systemd и Nginx.

Результат: загрузки отправляются на VPS из браузера или Telegram; прогресс и файлы доступны в веб-панели. Код и скриншот доступны ниже.

Snapbuild Composer

Векторный редактор с подбором иллюстраций по смыслу запроса прямо в браузере

React + TypeScript + Transformers.js

От текстовой идеи к редактируемой SVG-композиции

Задача: собирать композиции из готовой библиотеки SVG по названиям объектов или смыслу запроса, сохраняя векторную структуру.

Моя роль: выполнил тестовое задание с Codex: разбор требований, интерфейс редактора, работа с SVG, семантический поиск и проверки.

Решение: React и TypeScript управляют сценой и слоями; модель MiniLM через Transformers.js подбирает объекты в Web Worker. IndexedDB сохраняет проект локально.

Результат: редактор из 20 исходных SVG с перемещением, масштабированием, поворотом, палитрами, undo/redo и экспортом SVG и JSON-проекта. Приложение доступно на GitHub Pages.

Демо Код

Для первого поиска по смыслу загружается модель (~150 МБ). Можно сразу выбрать режим «По названиям» без модели. API-ключ не нужен; запрос и SVG обрабатываются локально.

Подбор из готовой библиотеки

Модель сопоставляет запрос с описаниями существующих объектов. Новые иллюстрации не генерируются; результат можно скорректировать вручную.

Иллюстрации предоставлены для тестового задания и принадлежат владельцу библиотеки.
